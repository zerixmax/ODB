## 2. Što je napravljeno danas (15.10.2026.)

### 2.1. Proširenje Prisma sheme — `prisma/schema.prisma`

Model `Project` dobio dva nova polja (`prisma/schema.prisma:55-57`):

```prisma
// Interaktivni HTML Runbook / Master TODO
todoHtml       String?   // Spremljeni samostalni HTML dokument ili JSON struktura
todoState      String?   // JSON stanje kvačica, npr. {"t1": true, "t2": true, "t5": false}
```

- `todoHtml` — rezervirano za cijeli samostalni HTML dokument (ili JSON strukturu faza).
- `todoState` — JSON mapa `data-id → bool` sa stanjem kvačica.

Primijenjeno:

```bash
npx prisma db push      # schema u sync s dev.db
npx prisma generate     # regeneriran Prisma Client (v6.4.1)
```

### 2.2. API endpoint za "Auto-Sync" — `src/app/api/todo-sync/route.ts`

Nova ruta prima `POST { domain, progress, stateJson }`, pronalazi projekt po domeni
(`domain: { contains }`), upisuje `progress`, `todoState` i `lastUpdateDate`, te
`revalidatePath("/")`.

- `POST` → `{ ok: true, updated: <count> }`; greška → `500 { ok:false, error }`.
- `OPTIONS` → CORS preflight (`Access-Control-Allow-Origin: *`, metode `POST, OPTIONS`).
- **Import prilagođen bazi**: klijent se izvozi kao `prisma` (`src/lib/db.ts:7`), ne `db`.

### 2.3. HTML predložak — `MPS26_Master_TODO.html` (univerzalni obrazac)

Datoteka: `~/Preuzimanja/MPS26_Master_TODO.html` (izvan repo-a). Dodano:

1. **Status bedž** u `.progress-header`: `<span id="odb-sync-status">⚡ ODB Standby</span>`.
2. **Nadograđeni `<script>` blok** s:
   - konstantama `PROJECT_DOMAIN` i `ODB_API_URL`;
   - `getCurrentState()` / `calculatePercent()`;
   - `syncWithODB(percent, state)` — `fetch` POST + vizualni status (Sync ✓ / Projekt nije

   - `resetProgress()` koji usklađuje i ODB;
   - LocalStorage ostaje primarni izvor → radi i kad je ODB ugašen.

## 4. Tehničke napomene / caveati

- **CORS na stvarnom odgovoru**: `OPTIONS` vraća CORS headere, ali **`POST` odgovor ih ne
  sadrži**. Ako se HTML otvara s `file://` (origin `null`), preflight prođe, ali čitanje
  `res.json()` biva blokirano → UI prikaže "Lokalno (ODB offline)" iako je DB upisan server-side.
  Rješenje: dodati CORS headere i na `POST` odgovor (ili servirati HTML s istog origina).
- **Port**: uskladiti `ODB_API_URL` s portom na kojem ODB stvarno sluša (dev 3100 vs. hardkodirano
  3000).
- **Match domene**: `PROJECT_DOMAIN` mora biti podstring domene u bazi (`domain: { contains }`),
  npr. `marcopolosport.com`.
- **Ne commitati** `dev.db` stanje; shema se rekonstruira `db push` + `db:seed`.
- Iz prethodnih verzija (preneseno): putanja s razmakom → citirati; IPv6 ne radi → `curl -4`;
  `tsx` nije instaliran → `node --experimental-strip-types`; `date-fns` deklariran ali neinstaliran
  → koristiti helpere iz `src/lib/utils.ts`.
