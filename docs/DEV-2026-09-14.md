## 2. Što je napravljeno danas (14.09.2026.)

### 2.1. Autentikacija — "Moj račun" (V2.4)

- **Cilj**: jednostavna single-user autentikacija za cockpit, spremna za nadogradnju na ozbiljniju auth shemu. **Bez novih dependencyja** — Node built-in `crypto` (HMAC-SHA256, `timingSafeEqual`, `base64url`).
- **Kredencijale** (`AUTH_USER`, `AUTH_PASSWORD`, `SESSION_SECRET`) upisane samo u `.env` (lozinka + tajni ključ generirani, izvan gita; `.env` već u `.gitignore`). `.env.example` sadrži prazan template.
- **Sesija**: cookie `odb_session` (httpOnly, `sameSite:"lax"`, `path:"/"`, `secure` u production; TTL 7 dana → `SESSION_TTL_MS`).
- **Nove datoteke**:
  - `src/lib/auth.ts` — `SESSION_COOKIE`, `SESSION_TTL_MS`, `verifyCredentials`, `signSession`, `verifyToken`.
  - `src/lib/session.ts` — `getSessionUser`, `requireSession` (pripremljeni guardovi).
  - `src/lib/auth-actions.ts` — `login` (`useActionState` forma) i `logout`.
  - `src/app/login/page.tsx` + `src/app/login/LoginForm.tsx` — login UI.
  - `src/proxy.ts` — **Vodeća napomena**: u Next.js 16.3.5 `middleware` je **deprecated** → koristi se `src/proxy.ts` s `export function proxy(request: NextRequest)` i `config.matcher` (`["/", "/login", "/projects/:path*"]`); neautenticirane rute → redirect na `/login?from=...`.
- **Odjava**: gumb u `Header.tsx` i `ProjectDetailClient.tsx` (`logout` action, `LogOut` ikona iz lucide).
- **docker-compose.yml**: dodane env varijable `AUTH_USER=${AUTH_USER:-olead}`, `AUTH_PASSWORD`, `SESSION_SECRET`.

## 3. Tehničke napomene iz V2.2 (preneseno)

- **Putanja s razmakom** — svuda citirati (WorkingDirectory, exec pozivi).
- **IPv6 ne radi** na ovoj mreži → preuzimanja koristiti IPv4 (`curl -4`).
- **`tsx` nije instaliran** → TS skripte pokretati `node --experimental-strip-types`.
- `date-fns` deklariran ali **nije instaliran** → koristiti `src/lib/utils.ts` helpere.
- Filesystem je **NTFS (ntfs3)** → binarne datoteke povremeno korumpirane; pri sumnjivim native greškama provjeriti `file`/`readelf` veličine.
