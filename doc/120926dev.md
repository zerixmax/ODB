## 🚀 Što je novo u V2.1

### 1. Čišćenje vršne trake i filtera (Zero noise)
- **Jedna raketa:** Uklonjene dvostruke ikone rakete. CI/CD je sveden na jedan čisti bedž: `🚀 Coolify CI/CD`.
- **Uklonjen suvišni šum:** Izbačeni nebitni badgevi s vrha.
- **Fokusirana jutarnja traka s 7+1 filterom:**
  - `Svi (17)` | `🔥 Hitno Danas (3)` | `💻 Laptop (4)` | `🚀 Coolify (5)` | `📦 VPS (8)` | `🌐 Totohost (9)` | `💶 Neplaćeno (6)` | `📦 Arhiva (0)`

### 2. Prošireni Model Podataka (`prisma/schema.prisma`)
- `hosting`: String `@default("VPS")` // "VPS" (Coolify/Docker/MyDataKnox) ili "TOTOHOST" (cPanel/Shared)
- `price`: Float? // npr. 550.00, 650.00, 899.00
- `isPaid`: Boolean `@default(false)` // Zeleni bedž `[ PLAĆENO ]` ili narančasti/crveni `[ NIJE PLAĆENO ]`
- `notes`: String? // Tehnički detalji, Coolify App UUID, portovi kontejnera, PostgreSQL/SQLite postavke, deploy upute
- `devDevice`: String `@default("WORKSTATION")` // "LAPTOP" vs "WORKSTATION"
- `hasGitBackup`: Boolean `@default(true)`
- `hasCicd`: Boolean `@default(false)`

### 3. Pojedinačna stranica za svaki projekt (`/projects/[id]`)
- Ruta: `src/app/projects/[id]/page.tsx` & `ProjectDetailClient.tsx`
- **Header s brzim statusom:**
  - Tipka `← Natrag na Cockpit` za trenutni povratak na dashboard
  - Prekidač `[ 📦 VPS | 🌐 TOTOHOST ]` (1-klik Server Action toggle)
  - Prekidač `[ 💶 PLAĆENO | ⚠️ NIJE PLAĆENO ]` + iznos u € (1-klik toggle)
  - Prekidač radnog mjesta `[ 💻 Laptop | 🖥️ Radna stanica ]` (1-klik toggle)
  - CI/CD Webhook Prekidač `[ 🚀 Coolify Webhook ]`
  - Selektori faze (`BACKLOG`, `IN_PROGRESS`, `WAITING_VPS`, `PRODUCTION`, `MAINTENANCE`), prioriteta i dovršenosti
- **Područje za opaske (Technical Notes):**
  - Veliko polje (textarea) za upis tehničkih detalja
  - Tipka `💾 Spremi Opaske` uz vizualnu potvrdu spremanja
  - Brzi gumbi za umetanje predložaka (`+ Coolify UUID`, `+ Port`, `+ PostgreSQL / SQLite`, `+ Deploy Koraci`)
- **Logirani sati (Time Tracking):**
  - Pregledna lista svih unosa sati za taj specifični projekt s opisom i datumom
  - Brzi unos: `+15 min`, `+30 min`, `+1 sat`
  - Obrazac za ručni unos (sati + opis zadatka)
  - Brisanje unosa radnog vremena
- **Brzi linkovi:**
  - Direktan link na live/test stranicu
  - Link na Google Doc / Drive specifikaciju
  - Coolify VPS konzola (MyDataKnox)

### 4. Server Actions (`src/lib/actions.ts`)
- `updateProjectNotes(id: string, notes: string)`
- `togglePaymentStatus(id: string, isPaid: boolean)`
- `toggleHosting(id: string, currentHosting: string)`
- `toggleDevDevice(id: string, currentDevice: string)`
- `toggleCicd(id: string, currentCicd: boolean)`
- `quickAddTimeLog(projectId: string, hours: number, description?: string)`
- `deleteTimeLog(id: string, projectId?: string)`
- Automatska revalidacija obje rute (`/` i `/projects/[id]`).
